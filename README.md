# Amber 
An online application that uses Cognitive Stimulation and Reminiscence Therapy to help people with dementia.
## Descrition
An AI driven online application that uses Cognitive Stimulation Therapy and Reminiscence Therapy through interactive photo storytelling, voice-to-text conversion, and a caregiver dashboard.

While dementia is irreversible, structured social engagement and conversational AI can alleviate symptoms, preserve the patient’s personhood, and provide mental relief for caregivers.  

Primary User (Patient): Arthur (Age 78), an early-to-moderate stage Alzheimer’s patient who needs an easy, frustration-free tool to reminisce and stay mentally active. 
Secondary User (Caregiver): Sarah (Age 45), an overworked family caregiver who needs a reliable dashboard to manage photos, monitor engagement, and reduce her 24/7 caregiving burden.
